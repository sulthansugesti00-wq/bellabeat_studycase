# bellabeat_studycase
Analyzed Bellabeat smart device usage data to identify membership conversion patterns. Methodology used K-Means for user segmentation based on peer-reviewed research for the criterion
<br>
## Project overview
The purpose of this project is to identify Bellabeat user segmentation to support the Bellabeat marketing campaign in membership conversion
<br>
## Data source
The data source used in this case study is Fitbit Fitness Tracker Data from file Fitabase Data 3.12.16-4.11.16
and merged with Fitabase Data 4.12.16-5.12.16. These datasets were generated by respondents to a distributed survey via Amazon Mechanical Turk between
03.12.2016-05.12.2016. Thirty eligible Fitbit users consented to the submission of personal tracker data,
including minute-level output for physical activity, heart rate, and sleep monitoring
<br>
